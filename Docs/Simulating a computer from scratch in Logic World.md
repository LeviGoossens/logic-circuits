# Conventions
- where input:
	- **left to right** equals **small to big**
	- **up to down** equals **small to big**
- where output:
	- **left to right** equals **big to small**
	- **up to down** equals **big to small**
- mechanical construction in light and dark gray alternates (ideally)
- inputs and outputs are labeled with letters

# Components
using logic gates we build small modules like:
- 8-bit xor module (can xor two 8-bit values)
- 8-bit adder module (can add two 8-bit values)
- 8-bit not module (can invert one 8-bit value)
- 8-bit memory (can store one 8-bit value)
- 8-bit decoder (can decode one 8-bit value into 8-bit characters)
- 8-bit AU (can add or subtract 8-bit values)
