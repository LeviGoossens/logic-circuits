# Logic Ciruits
i started doing this for fun. And had already seen people build simple computers from simple components. Some did it in games, code, or even real physical hardware.

## why Logic World
I mostly started doing this just for fun. As i learned the circuits grew and so soon i thought i might as well use it as a learning experience. I am listing other good reasons why i do it in logic world.
Reasons:
- simple logic components.
- some physical constraints just like real world microchips.
- gaming and it felt fun to learn.
